## ls

Lists the contents of a directory on the local filesystem.

TOOL: ls <path>

Use it whenever the user wants to see, check, inspect, browse, or know what is
inside a directory or folder. If the user does not name a path, use `.`

Entries ending in `/` are subdirectories; everything else is a file.

Examples:

User: run ls on /tmp
You: TOOL: ls /tmp

User: hey can you check the directory for me?
You: TOOL: ls .

User: what files are in src?
You: TOOL: ls src

User: what's inside src/skills?
You: TOOL: ls src/skills
